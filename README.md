### 🚀 Featured Projects

#### 🗺️ [Wander — AI Smart Travel Planner](https://github.com/rujutaphaltankar/wander)
*A full-stack AI-driven itinerary planner and travel organizer.*
* **Tech Stack**: React, Vite, TypeScript, Node.js, Express, Prisma, SQLite, Tailwind CSS.
* **Key Features**: Dynamic user authentication (JWT), AI-generated itineraries (OpenAI/Anthropic integration), interactive budget tracker, and favorite locations management.

#### 👥 [Social Network Web Application](https://github.com/rujutaphaltankar/social_network_js)
*A dynamic web application with responsive UI/UX for user interactions.*
* **Tech Stack**: Vanilla JavaScript, HTML5, CSS3.
* **Key Features**: Implemented dynamic feeds, user profiles, status updates, and interactive user interactions without external framework overhead.

#### 📊 [Social Network — Data Structures Backend](https://github.com/rujutaphaltankar/socialnetwork_ds)
*The backend algorithmic modeling of social connections.*
* **Tech Stack**: Java, Core Data Structures (Graphs, Linked Lists, Queues).
* **Key Features**: Modeled user connections using graphs and traversal algorithms, applying object-oriented design and clean data architecture.
